# Lessons and reflection

## Design conclusions — not claims of hands-on execution

- Log collection and alert generation are separate stages; an empty alert search may be a coverage issue.
- A harmless simulation is useful when the telemetry and analyst reasoning are reproducible.
- Hardware planning affects whether a full SIEM is feasible.
- Process names and isolated failures need context before escalation.
- A small, supported ATT&CK mapping is more credible than tagging every action.
